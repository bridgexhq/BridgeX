Before you install

Each platform warns once

These builds aren't signed with a paid developer certificate, so the OS can't yet verify who made them. Nothing is wrong with the app - this is expected on first open.

macOS

  1. Open BridgeX-0.4.0-mac-arm64.dmg (Apple Silicon) or -mac-x64.dmg (Intel) and drag BridgeX onto Applications.
  2. Open BridgeX. macOS says it cannot verify the developer: click Done.
  3. Go to System Settings → Privacy & Security, scroll to Security, and click Open Anyway next to BridgeX. You only do this once.

Windows & Linux

Builds for this version haven't been produced yet. Once they're available, Windows will warn via SmartScreen (More info → Run anyway) and Linux AppImages will need chmod +x and FUSE (libfuse2 on Ubuntu 22.04 and newer), the same as earlier releases.

Verify

SHA-256 checksums

Run shasum -a 256 <file> (macOS/Linux) or certutil -hashfile <file> SHA256 (Windows) and compare.
