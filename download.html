Before you install

Each platform warns once

These builds aren't signed with a paid developer certificate, so the OS can't yet verify who made them. Nothing is wrong with the app — this is expected on first open.

macOS

  1. Open FileBird-0.3.2-mac-arm64.dmg (Apple Silicon) or -mac-x64.dmg (Intel) and drag FileBird onto Applications.
  2. Open FileBird. macOS says it cannot verify the developer: click Done.
  3. Go to System Settings → Privacy & Security, scroll to Security, and click Open Anyway next to FileBird. You only do this once.

Windows

  1. Run FileBird-0.3.2-win-x64-setup.exe.
  2. SmartScreen warns about an unrecognised app: choose More info → Run anyway.

Passwords are stored in Windows Credential Manager.

Linux

chmod +x FileBird-0.3.2-linux-x86_64.AppImage
./FileBird-0.3.2-linux-x86_64.AppImage

Saving passwords needs a Secret Service provider (GNOME Keyring or KWallet), and AppImages need FUSE (libfuse2 on Ubuntu 22.04 and newer).

Verify

SHA-256 checksums

Run shasum -a 256 <file> (macOS/Linux) or certutil -hashfile <file> SHA256 (Windows) and compare.
